### What I learned

This project helped me practice the basics of building a clean, centered card layout. I learned how to structure content semantically, use CSS to center elements on the page, and style text and spacing to match a design mockup.

I also improved my understanding of how a simple component can be built using:

- a parent container for the card
- a QR code image at the top
- a heading and short paragraph inside the card
- a neutral background and subtle shadow to match the design
